# NEVES GovTech! DPFin — distribuição

Programa compilado do DPFin (Prefeitura de Ribeirão das Neves/MG). Este repositório não contém código-fonte nem dados.

## ▶ [Verificar agora](https://github.com/0FelipeVenceslau0/DPFin-Neves/actions/workflows/verificar-agora.yml)

Abra o link acima e use **Run workflow** para liberar a versão enviada pelo ATUALIZADOR DPFIN-Neves. Cada computador
com o DPFin aberto a encontra em até 15 minutos (ou ao abrir o programa) e instala a versão nova no lugar da antiga,
preservando a pasta de dados.
